# Правила для Claude в этом репозитории

## Где работать
- Единственная рабочая копия проекта — **эта папка** (`C:\Program Files\KOD\warfront`).
- Не клонировать репозиторий в другие папки и не создавать копии проекта.
  Все правки — только здесь.
- Если уже запущены сервер или клиент (порты 8080 / 5173) — не останавливать их
  и не подключаться к ним тестовыми клиентами без разрешения.

## Git — решения принимает только владелец
- **Не создавать ветки.** Работать в текущей ветке.
- **Не делать коммиты** без явной просьбы владельца.
- **Никогда не пушить.** Решение о пуше кода принимает только владелец.
- Не делать `git checkout`, `reset`, `stash`, `rebase` и прочие операции,
  меняющие историю или текущую ветку, без явной просьбы.
- Не трогать чужие незакоммиченные изменения (например, `package-lock.json`).

## Как вести изменения
- После правок — показать список изменённых файлов (`git status`) и кратко,
  что и зачем поменялось. Дальше владелец решает сам.
- Перед проверкой в браузере или запуском серверов — сказать, на каких портах
  и что будет запущено.
